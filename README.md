# 📊 Sales Analytics Dashboard

## 📌 Overview

This project analyzes sales data to identify key business insights such as revenue trends, top-performing products, and customer behavior.

## 🛠 Tools Used

* SQL
* Python (Pandas)
* Power BI

## 🔍 Key Analysis

* Calculated total revenue and profit
* Analyzed monthly sales trends
* Identified top-performing products
* Analyzed sales by region and category

## 📈 Insights

* A small number of products contribute to most of the revenue
* Sales vary across different regions
* Certain categories perform better than others
